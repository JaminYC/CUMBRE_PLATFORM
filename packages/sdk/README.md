# @cumbre/sdk

Shared service contract layer for CUMBRE.

This package defines the interfaces that apps, backend services, and AI modules use to communicate with the platform. It depends on `@cumbre/types` for canonical domain entities and `@cumbre/schemas` for request and response payloads.

Contents:

- Service endpoint configuration
- Reusable service interfaces
- Cross-platform request and response contracts
- Shared read-model shapes for clients and orchestrators
