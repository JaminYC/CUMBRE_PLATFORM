# @cumbre/schemas

Declarative API contract layer for CUMBRE.

This package defines request and response types plus validation-friendly schema objects for cross-service communication. Domain entities are referenced from `@cumbre/types` instead of being duplicated here.

Contents:

- Request and response payload types
- Shared error envelope
- Declarative schema definitions ready for future validation adapters
- Contracts for auth, user profile, learning session, content, recommendation, tutor, analytics, and notification flows
