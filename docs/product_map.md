# Product Map

## User Surfaces

- `web_student`: learning, practice, feedback, and progress
- `web_teacher`: class management, insights, interventions, and content oversight
- `web_admin`: operations, reporting, governance, and platform controls
- `mobile`: on-the-go access for learning and notifications

## Core Platform Domains

- Identity and access
- Learning flow and progression
- Content management
- Analytics and reporting
- Notifications and communications
- User profile and preferences

## AI-Driven Capabilities

- Intelligent tutoring
- Personalized recommendations
- Retrieval-based assistance
- Adaptive sequencing
- Evaluation and quality scoring
